# software-engineering-portfolio

This is a portfolio for a lecture, Software Engineering (SWEN_IT801)

Yoshinao Ebisawa

L00179156

I expect to cover the module that provides a comprehensive exploration of key software engineering principles, process methodologies, and software quality management systems by building upon foundational concepts from Object-Oriented Analysis and Design and Project Management. Across the semester, the curriculum moves sequentially through software processes and change management, Agile software development methods and engineering techniques, software quality models and process improvement, software measurement and metrics using the Goal-Question-Metric approach, and software configuration management. Delivered through weekly one-hour lectures and two-hour research labs where students construct an individual GitHub portfolio, the coursework equips students to evaluate process models, establish measurement programs, appraise software quality, and effectively manage versioning, building, and releases for complex software projects.
